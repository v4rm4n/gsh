# GSH (Gleam Shell)

<!-- [![Package Version](https://img.shields.io/hexpm/v/gsh)](https://hex.pm/packages/gsh)
[![Hex Docs](https://img.shields.io/badge/hex-docs-ffaff3)](https://hexdocs.pm/gsh/) -->

A professional, interactive REPL for the Gleam language focused on developer experience, performance, and seamless project integration.

```sh
             _     
  __ _  ___ | |__  
 / _` |/ __|| '_ \ 
| (_| |\__ \| | | |
 \__, ||___/|_| |_|
 |___/  Interactive Gleam (v1.0.0)
 ```

 GSH runs directly inside your existing Gleam projects, giving you immediate access to your local modules, custom types, and Hex dependencies without any setup or global installations.
